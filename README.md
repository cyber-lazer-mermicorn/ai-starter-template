# AI Starter Template
## One-Click AI Project Setup

Start building AI apps in minutes. Pre-configured with OpenAI, Supabase, and best practices.

**Live:** https://ai-starter-template.vercel.app

---

## Quick Start

```bash
git clone https://github.com/cyber-lazer-mermicorn/ai-starter-template.git
cd ai-starter-template
npm install
cp .env.example .env.local
npm run dev
```

---

## What's Included

- OpenAI integration
- Supabase backend
- TypeScript strict mode
- ESLint + Prettier
- Docker support
- CI/CD ready
